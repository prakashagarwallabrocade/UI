  4. $y$ ର ମାନ (2) ରେ ବସାଇଲେ,
    x = c - \frac{ac}{a - b} = \frac{ac - bc - ac}{a - b} = \frac{-bc}{a - b} = \frac{bc}{b - a}
  5. ଯାଞ୍ଚ : (1) ରେ $a\cdot\frac{bc}{b - a} + b\cdot\frac{-ac}{b - a} = \frac{abc - abc}{b - a} = 0$ ଏବଂ (2) ରେ $\frac{bc - ac}{b - a} = \frac{c(b - a)}{b - a} = c$ । ଉଭୟ ସମୀକରଣ ସିଦ୍ଧ ହେଉଛି ।

3ପ୍ରଶ୍ନ

ବଜ୍ରଗୁଣନ ପ୍ରଣାଳୀରେ ନିମ୍ନଲିଖ୍ତ ସହସମୀକରଣମାନଙ୍କ ସମାଧାନ କର ।

ପଦ୍ଧତି : ବକ୍ର ଗୁଣନ ପ୍ରଣାଳୀରେ ପ୍ରଥମେ ସମୀକରଣ ଦ୍ୱୟକୁ $a_1x + b_1y + c_1 = 0$ ଓ $a_2x + b_2y + c_2 = 0$ ରୂପରେ ଲେଖି $a_1, b_1, c_1, a_2, b_2, c_2$ ଚିହ୍ନଟ କରାଯାଏ । ତା'ପରେ ସୂତ୍ର $\frac{x}{b_1c_2 - b_2c_1} = \frac{y}{c_1a_2 - c_2a_1} = \frac{1}{a_1b_2 - a_2b_1}$ ରେ ବସାଇ $x$ ଓ $y$ ନିର୍ଣ୍ଣୟ କରାଯାଏ । ଚିହ୍ନ (+/−) ଉପରେ ବିଶେଷ ଧ୍ୟାନ ଦେବା ଆବଶ୍ୟକ ।

(i) $x + 2y + 1 = 0,\ 2x - 3y - 12 = 0$

ବ୍ୟବହୃତ ସୂତ୍ର

  • ବକ୍ର ଗୁଣନ ସୂତ୍ର
    \frac{x}{b_1c_2 - b_2c_1} = \frac{y}{c_1a_2 - c_2a_1} = \frac{1}{a_1b_2 - a_2b_1}
    📖 ଅନୁଚ୍ଛେଦ 1.2. (ସହ ସମୀକରଣଦ୍ୱୟର ବୀଜଗାଣିତିକ ସମାଧାନ) — (iii) ବକ୍ର ଗୁଣନ, ସୂତ୍ର (4)
  1. ଦତ୍ତ ସହସମୀକରଣ ଦ୍ୱୟକୁ $a_1x + b_1y + c_1 = 0$ ଓ $a_2x + b_2y + c_2 = 0$ ରୂପରେ ଲେଖିଲେ,
    x + 2y + 1 = 0, \qquad 2x - 3y - 12 = 0
  2. ଏଠାରେ ସହଗ ଓ ଧ୍ରୁବକ ପଦଗୁଡ଼ିକ :
    a_1 = 1,\ b_1 = 2,\ c_1 = 1;\qquad a_2 = 2,\ b_2 = -3,\ c_2 = -12
  3. ବକ୍ର ଗୁଣନ ସୂତ୍ରର ହର ତିନିଟି ନିର୍ଣ୍ଣୟ କଲେ,
    b_1c_2 - b_2c_1 = 2(-12) - (-3)(1) = -21,\quad c_1a_2 - c_2a_1 = 1(2) - (-12)(1) = 14,\quad a_1b_2 - a_2b_1 = 1(-3) - 2(2) = -7
  4. ସୂତ୍ରରେ ବସାଇଲେ,
    \frac{x}{-21} = \frac{y}{14} = \frac{1}{-7} \Rightarrow x = \frac{-21}{-7} = 3,\quad y = \frac{14}{-7} = -2
  5. ଯାଞ୍ଚ : $3 - 4 + 1 = 0$ ଏବଂ $6 + 6 - 12 = 0$ । ଉଭୟ ସମୀକରଣ ସିଦ୍ଧ ହେଉଛି ।

ଉତ୍ତର : $x = 3,\ y = -2$ ଅର୍ଥାତ୍ ନିର୍ଣ୍ଣେୟ ସମାଧାନ $(3,\ -2)$ ।

(ii) $2x + 5y = 1,\ 2x + 3y = 3$

ବ୍ୟବହୃତ ସୂତ୍ର (ପୂର୍ବପରି)
  • ବକ୍ର ଗୁଣନ ସୂତ୍ର
    \frac{x}{b_1c_2 - b_2c_1} = \frac{y}{c_1a_2 - c_2a_1} = \frac{1}{a_1b_2 - a_2b_1}
    📖 ଅନୁଚ୍ଛେଦ 1.2. (ସହ ସମୀକରଣଦ୍ୱୟର ବୀଜଗାଣିତିକ ସମାଧାନ) — (iii) ବକ୍ର ଗୁଣନ, ସୂତ୍ର (4)
  1. ଦତ୍ତ ସହସମୀକରଣ ଦ୍ୱୟକୁ $a_1x + b_1y + c_1 = 0$ ଓ $a_2x + b_2y + c_2 = 0$ ରୂପରେ ଲେଖିଲେ,
    2x + 5y - 1 = 0, \qquad 2x + 3y - 3 = 0
  2. ଏଠାରେ ସହଗ ଓ ଧ୍ରୁବକ ପଦଗୁଡ଼ିକ :
    a_1 = 2,\ b_1 = 5,\ c_1 = -1;\qquad a_2 = 2,\ b_2 = 3,\ c_2 = -3
  3. ବକ୍ର ଗୁଣନ ସୂତ୍ରର ହର ତିନିଟି ନିର୍ଣ୍ଣୟ କଲେ,
    b_1c_2 - b_2c_1 = 5(-3) - 3(-1) = -12,\quad c_1a_2 - c_2a_1 = (-1)(2) - (-3)(2) = 4,\quad a_1b_2 - a_2b_1 = 2(3) - 2(5) = -4
  4. ସୂତ୍ରରେ ବସାଇଲେ,
    \frac{x}{-12} = \frac{y}{4} = \frac{1}{-4} \Rightarrow x = \frac{-12}{-4} = 3,\quad y = \frac{4}{-4} = -1
  5. ଯାଞ୍ଚ : $2(3) + 5(-1) = 1$ ଏବଂ $2(3) + 3(-1) = 3$ । ଉଭୟ ସମୀକରଣ ସିଦ୍ଧ ହେଉଛି ।

ଉତ୍ତର : $x = 3,\ y = -1$ ଅର୍ଥାତ୍ ନିର୍ଣ୍ଣେୟ ସମାଧାନ $(3,\ -1)$ ।

(iii) $x + 6y + 1 = 0,\ 2x + 3y + 8 = 0$

ବ୍ୟବହୃତ ସୂତ୍ର (ପୂର୍ବପରି)
  • ବକ୍ର ଗୁଣନ ସୂତ୍ର
    \frac{x}{b_1c_2 - b_2c_1} = \frac{y}{c_1a_2 - c_2a_1} = \frac{1}{a_1b_2 - a_2b_1}
    📖 ଅନୁଚ୍ଛେଦ 1.2. (ସହ ସମୀକରଣଦ୍ୱୟର ବୀଜଗାଣିତିକ ସମାଧାନ) — (iii) ବକ୍ର ଗୁଣନ, ସୂତ୍ର (4)
  1. ଦତ୍ତ ସହସମୀକରଣ ଦ୍ୱୟକୁ $a_1x + b_1y + c_1 = 0$ ଓ $a_2x + b_2y + c_2 = 0$ ରୂପରେ ଲେଖିଲେ,
    x + 6y + 1 = 0, \qquad 2x + 3y + 8 = 0
  2. ଏଠାରେ ସହଗ ଓ ଧ୍ରୁବକ ପଦଗୁଡ଼ିକ :
    a_1 = 1,\ b_1 = 6,\ c_1 = 1;\qquad a_2 = 2,\ b_2 = 3,\ c_2 = 8
  3. ବକ୍ର ଗୁଣନ ସୂତ୍ରର ହର ତିନିଟି ନିର୍ଣ୍ଣୟ କଲେ,
    b_1c_2 - b_2c_1 = 6(8) - 3(1) = 45,\quad c_1a_2 - c_2a_1 = 1(2) - 8(1) = -6,\quad a_1b_2 - a_2b_1 = 1(3) - 2(6) = -9
  4. ସୂତ୍ରରେ ବସାଇଲେ,
    \frac{x}{45} = \frac{y}{-6} = \frac{1}{-9} \Rightarrow x = \frac{45}{-9} = -5,\quad y = \frac{-6}{-9} = \frac{2}{3}
  5. ଯାଞ୍ଚ : $-5 + 6\cdot\frac{2}{3} + 1 = -5 + 4 + 1 = 0$ ଏବଂ $-10 + 3\cdot\frac{2}{3} + 8 = -10 + 2 + 8 = 0$ । ଉଭୟ ସମୀକରଣ ସିଦ୍ଧ ହେଉଛି ।

ଉତ୍ତର : $x = -5,\ y = \frac{2}{3}$ ଅର୍ଥାତ୍ ନିର୍ଣ୍ଣେୟ ସମାଧାନ $\left(-5,\ \frac{2}{3}\right)$ ।

(iv) $\frac{x}{a} + \frac{y}{b} = a + b$ , $\frac{x}{a^2} + \frac{y}{b^2} = 2$

ବ୍ୟବହୃତ ସୂତ୍ର (ପୂର୍ବପରି)
  • ବକ୍ର ଗୁଣନ ସୂତ୍ର
    \frac{x}{b_1c_2 - b_2c_1} = \frac{y}{c_1a_2 - c_2a_1} = \frac{1}{a_1b_2 - a_2b_1}
    📖 ଅନୁଚ୍ଛେଦ 1.2. (ସହ ସମୀକରଣଦ୍ୱୟର ବୀଜଗାଣିତିକ ସମାଧାନ) — (iii) ବକ୍ର ଗୁଣନ, ସୂତ୍ର (4)
  1. ଦତ୍ତ ସହସମୀକରଣ ଦ୍ୱୟକୁ $a_1x + b_1y + c_1 = 0$ ରୂପରେ ଲେଖିଲେ ($a \neq 0,\ b \neq 0$),
    \frac{1}{a}\,x + \frac{1}{b}\,y - (a + b) = 0, \qquad \frac{1}{a^2}\,x + \frac{1}{b^2}\,y - 2 = 0
  2. ଏଠାରେ ସହଗ ଓ ଧ୍ରୁବକ ପଦଗୁଡ଼ିକ :
    a_1 = \frac{1}{a},\ b_1 = \frac{1}{b},\ c_1 = -(a + b);\qquad a_2 = \frac{1}{a^2},\ b_2 = \frac{1}{b^2},\ c_2 = -2
  3. ପ୍ରଥମ ହର :
    b_1c_2 - b_2c_1 = \frac{1}{b}(-2) - \frac{1}{b^2}\{-(a + b)\} = \frac{-2b + a + b}{b^2} = \frac{a - b}{b^2}
  4. ଦ୍ୱିତୀୟ ହର :
    c_1a_2 - c_2a_1 = -\frac{a + b}{a^2} + \frac{2}{a} = \frac{-a - b + 2a}{a^2} = \frac{a - b}{a^2}
  5. ତୃତୀୟ ହର :
    a_1b_2 - a_2b_1 = \frac{1}{ab^2} - \frac{1}{a^2b} = \frac{a - b}{a^2b^2}
  6. ସୂତ୍ରରେ ବସାଇଲେ ($a \neq b$),
    x = \frac{(a - b)/b^2}{(a - b)/(a^2b^2)} = a^2,\qquad y = \frac{(a - b)/a^2}{(a - b)/(a^2b^2)} = b^2
  7. ଯାଞ୍ଚ : $\frac{a^2}{a} + \frac{b^2}{b} = a + b$ ଏବଂ $\frac{a^2}{a^2} + \frac{b^2}{b^2} = 1 + 1 = 2$ । ଉଭୟ ସମୀକରଣ ସିଦ୍ଧ ହେଉଛି ।

ଉତ୍ତର : $x = a^2,\ y = b^2$ ଅର୍ଥାତ୍ ନିର୍ଣ୍ଣେୟ ସମାଧାନ $(a^2,\ b^2)$ । ($a \neq b$)

(v) $x + 6y + 1 = 0,\ 2x + 3y + 8 = 0$

ବ୍ୟବହୃତ ସୂତ୍ର (ପୂର୍ବପରି)
  • ବକ୍ର ଗୁଣନ ସୂତ୍ର
    \frac{x}{b_1c_2 - b_2c_1} = \frac{y}{c_1a_2 - c_2a_1} = \frac{1}{a_1b_2 - a_2b_1}
    📖 ଅନୁଚ୍ଛେଦ 1.2. (ସହ ସମୀକରଣଦ୍ୱୟର ବୀଜଗାଣିତିକ ସମାଧାନ) — (iii) ବକ୍ର ଗୁଣନ, ସୂତ୍ର (4)
ଟିପ୍ପଣୀ : ପ୍ରଶ୍ନ (v) ର ସମୀକରଣ ଦ୍ୱୟ ପ୍ରଶ୍ନ (iii) ସହ ହୁବହୁ ସମାନ ଭାବେ ମୁଦ୍ରିତ, ତେଣୁ ଉତ୍ତର ମଧ୍ୟ (iii) ପରି । ପୁସ୍ତକର ଉତ୍ତରମାଳାରେ ଦିଆଯାଇଥିବା $(2,\ -3)$ ଏହି ସମୀକରଣକୁ ସିଦ୍ଧ କରେ ନାହିଁ ($2 + 6(-3) + 1 = -15 \neq 0$); ଅର୍ଥାତ୍ ପ୍ରଶ୍ନ (v) ରେ ମୁଦ୍ରଣ ତ୍ରୁଟି ରହିଛି ।
  1. ଦତ୍ତ ସହସମୀକରଣ ଦ୍ୱୟକୁ $a_1x + b_1y + c_1 = 0$ ଓ $a_2x + b_2y + c_2 = 0$ ରୂପରେ ଲେଖିଲେ,
    x + 6y + 1 = 0, \qquad 2x + 3y + 8 = 0
  2. ଏଠାରେ ସହଗ ଓ ଧ୍ରୁବକ ପଦଗୁଡ଼ିକ :
    a_1 = 1,\ b_1 = 6,\ c_1 = 1;\qquad a_2 = 2,\ b_2 = 3,\ c_2 = 8
  3. ବକ୍ର ଗୁଣନ ସୂତ୍ରର ହର ତିନିଟି ନିର୍ଣ୍ଣୟ କଲେ,
    b_1c_2 - b_2c_1 = 48 - 3 = 45,\quad c_1a_2 - c_2a_1 = 2 - 8 = -6,\quad a_1b_2 - a_2b_1 = 3 - 12 = -9
  4. ସୂତ୍ରରେ ବସାଇଲେ,
    \frac{x}{45} = \frac{y}{-6} = \frac{1}{-9} \Rightarrow x = -5,\quad y = \frac{2}{3}
  5. ଯାଞ୍ଚ : $-5 + 4 + 1 = 0$ ଏବଂ $-10 + 2 + 8 = 0$ । ଉଭୟ ସମୀକରଣ ସିଦ୍ଧ ହେଉଛି ।

ଉତ୍ତର : $x = -5,\ y = \frac{2}{3}$ ଅର୍ଥାତ୍ ନିର୍ଣ୍ଣେୟ ସମାଧାନ $\left(-5,\ \frac{2}{3}\right)$ ।

(vi) $4x - 9y = 0,\ 3x + 2y - 35 = 0$

ବ୍ୟବହୃତ ସୂତ୍ର (ପୂର୍ବପରି)
  • ବକ୍ର ଗୁଣନ ସୂତ୍ର
    \frac{x}{b_1c_2 - b_2c_1} = \frac{y}{c_1a_2 - c_2a_1} = \frac{1}{a_1b_2 - a_2b_1}
    📖 ଅନୁଚ୍ଛେଦ 1.2. (ସହ ସମୀକରଣଦ୍ୱୟର ବୀଜଗାଣିତିକ ସମାଧାନ) — (iii) ବକ୍ର ଗୁଣନ, ସୂତ୍ର (4)
  1. ଦତ୍ତ ସହସମୀକରଣ ଦ୍ୱୟକୁ $a_1x + b_1y + c_1 = 0$ ଓ $a_2x + b_2y + c_2 = 0$ ରୂପରେ ଲେଖିଲେ,
    4x - 9y + 0 = 0, \qquad 3x + 2y - 35 = 0
  2. ଏଠାରେ ସହଗ ଓ ଧ୍ରୁବକ ପଦଗୁଡ଼ିକ :
    a_1 = 4,\ b_1 = -9,\ c_1 = 0;\qquad a_2 = 3,\ b_2 = 2,\ c_2 = -35
  3. ବକ୍ର ଗୁଣନ ସୂତ୍ରର ହର ତିନିଟି ନିର୍ଣ୍ଣୟ କଲେ,
    b_1c_2 - b_2c_1 = (-9)(-35) - 2(0) = 315,\quad c_1a_2 - c_2a_1 = 0 - (-35)(4) = 140,\quad a_1b_2 - a_2b_1 = 8 - (-27) = 35
  4. ସୂତ୍ରରେ ବସାଇଲେ,
    \frac{x}{315} = \frac{y}{140} = \frac{1}{35} \Rightarrow x = \frac{315}{35} = 9,\quad y = \frac{140}{35} = 4
  5. ଯାଞ୍ଚ : $36 - 36 = 0$ ଏବଂ $27 + 8 - 35 = 0$ । ଉଭୟ ସମୀକରଣ ସିଦ୍ଧ ହେଉଛି ।

ଉତ୍ତର : $x = 9,\ y = 4$ ଅର୍ଥାତ୍ ନିର୍ଣ୍ଣେୟ ସମାଧାନ $(9,\ 4)$ ।

ପୁସ୍ତକର ଉତ୍ତରମାଳା : 3.(i)$(3, -2)$, (ii) $(3, -1)$, (iii) $(-5, \frac{2}{3})$, (iv) $(a^2, b^2)$, (v)$(2, -3)$, (vi) $(9,4)$ ; ✗ ଉତ୍ତରମାଳା

ଯାଞ୍ଚ ଟିପ୍ପଣୀ : (v) ପୁସ୍ତକରେ ପ୍ରଶ୍ନ (v) ଓ (iii) ର ସମୀକରଣ ହୁବହୁ ସମାନ ମୁଦ୍ରିତ (ପୃଷ୍ଠା ଚିତ୍ରରେ ଯାଞ୍ଚ କରାଯାଇଛି) । ଉତ୍ତରମାଳାର $(2,\ -3)$ ଏହି ସମୀକରଣକୁ ସିଦ୍ଧ କରେ ନାହିଁ, ତେଣୁ ପ୍ରଶ୍ନ (v) ରେ ମୁଦ୍ରଣ ତ୍ରୁଟି ଅଛି ।

4ପ୍ରଶ୍ନ

ନିମ୍ନଲିଖ୍ତ ସହସମୀକରଣମାନଙ୍କ ସମାଧାନ କର ।

ପଦ୍ଧତି : ଏଠାରେ ଅଧିକାଂଶ ସମୀକରଣ ସିଧାସଳଖ ଏକଘାତୀ ନୁହଁନ୍ତି । $\frac{1}{x},\ \frac{1}{y},\ \frac{1}{x+y}$ ଭଳି ପଦ ପାଇଁ ନୂଆ ରାଶି ($u,\ v$) ନେଇ ବା ଭଗ୍ନାଂଶ ହଟାଇ ସମୀକରଣଗୁଡ଼ିକୁ ସରଳ ସହସମୀକରଣରେ ପରିଣତ କରାଯାଏ । ତା'ପରେ ଅପସାରଣ ବା ପ୍ରତିକଳ୍ପନ ପଦ୍ଧତିରେ ସମାଧାନ କରି ମୂଳ ରାଶିକୁ ଫେରିଯାଇ $x$ ଓ $y$ ନିର୍ଣ୍ଣୟ କରାଯାଏ ।

(i) $\frac{2}{x} + \frac{3}{y} = 17,\ \frac{1}{x} + \frac{1}{y} = 7$ $(x \neq 0,\ y \neq 0)$

ବ୍ୟବହୃତ ସୂତ୍ର

  • ଅଣ ସରଳରେଖ୍ୟ ସହସମୀକରଣ : ଉପଯୁକ୍ତ ନୂଆ ରାଶି ନେଇ ସରଳ (ଏକଘାତୀ) ସହସମୀକରଣରେ ପରିଣତ କରିବା
    u = \frac{1}{x},\ v = \frac{1}{y} \;\Rightarrow\; a_1u + b_1v + c_1 = 0,\ a_2u + b_2v + c_2 = 0
    📖 ଅନୁଚ୍ଛେଦ 1.4. (ଅଣ ସରଳରେଖ୍ୟ ସହସମୀକରଣ)
  • ଅପସାରଣ ପଦ୍ଧତି : ସହଗ ସମାନ କରି ଯୋଗ ବା ବିୟୋଗ ଦ୍ୱାରା ଗୋଟିଏ ରାଶିକୁ ଅପସାରଣ
    a_2(a_1x + b_1y + c_1) - a_1(a_2x + b_2y + c_2) = 0 \Rightarrow (a_2b_1 - a_1b_2)\,y + (a_2c_1 - a_1c_2) = 0
    📖 ଅନୁଚ୍ଛେଦ 1.2. (ସହ ସମୀକରଣଦ୍ୱୟର ବୀଜଗାଣିତିକ ସମାଧାନ) — (II) ଅପସାରଣ ପଦ୍ଧତି
  1. $\frac{1}{x} = u$ ଓ $\frac{1}{y} = v$ ନେଲେ ଦତ୍ତ ସମୀକରଣ ଦ୍ୱୟ ହେବ,
    2u + 3v = 17 \quad \ldots(1), \qquad u + v = 7 \quad \ldots(2)
  2. (2) କୁ 2 ଦ୍ୱାରା ଗୁଣନ କରି (1) ରୁ ବିୟୋଗ କଲେ,
    (2u + 3v) - (2u + 2v) = 17 - 14 \Rightarrow v = 3
  3. (2) ରୁ,
    u = 7 - 3 = 4
  4. ଅତଏବ $\frac{1}{x} = 4 \Rightarrow x = \frac{1}{4}$ ଓ $\frac{1}{y} = 3 \Rightarrow y = \frac{1}{3}$ ।
  5. ଯାଞ୍ଚ : $2(4) + 3(3) = 17$ ଏବଂ $4 + 3 = 7$ । ଉଭୟ ସମୀକରଣ ସିଦ୍ଧ ହେଉଛି ।

ଉତ୍ତର : $x = \frac{1}{4},\ y = \frac{1}{3}$ ଅର୍ଥାତ୍ ନିର୍ଣ୍ଣେୟ ସମାଧାନ $\left(\frac{1}{4},\ \frac{1}{3}\right)$ ।

(ii) $\frac{5}{x} + 6y = 13,\ \frac{3}{x} + 20y = 35$ $(x \neq 0)$

    a_2(a_1x + b_1y + c_1) - a_1(a_2x + b_2y + c_2) = 0 \Rightarrow (a_2b_1 - a_1b_2)\,y + (a_2c_1 - a_1c_2) = 0
    📖 ଅନୁଚ୍ଛେଦ 1.2. (ସହ ସମୀକରଣଦ୍ୱୟର ବୀଜଗାଣିତିକ ସମାଧାନ) — (II) ଅପସାରଣ ପଦ୍ଧତି
  1. $\frac{1}{x} = u$ ନେଲେ ଦତ୍ତ ସମୀକରଣ ଦ୍ୱୟ ହେବ,
    5u + 6y = 13 \quad \ldots(1), \qquad 3u + 20y = 35 \quad \ldots(2)
  2. $u$ ର ସହଗ ସମାନ କରିବା ପାଇଁ (1) କୁ 3 ଓ (2) କୁ 5 ଦ୍ୱାରା ଗୁଣନ କଲେ,
    15u + 18y = 39 \quad \ldots(3), \qquad 15u + 100y = 175 \quad \ldots(4)
  3. (4) ରୁ (3) କୁ ବିୟୋଗ କଲେ,
    82y = 136 \Rightarrow y = \frac{136}{82} = \frac{68}{41}
  4. $y$ ର ମାନ (1) ରେ ବସାଇଲେ,
    5u = 13 - 6\cdot\frac{68}{41} = \frac{533 - 408}{41} = \frac{125}{41} \Rightarrow u = \frac{25}{41}
  5. ଅତଏବ $\frac{1}{x} = \frac{25}{41} \Rightarrow x = \frac{41}{25}$ ।
  6. ଯାଞ୍ଚ : $5\cdot\frac{25}{41} + 6\cdot\frac{68}{41} = \frac{125 + 408}{41} = \frac{533}{41} = 13$ ଏବଂ $3\cdot\frac{25}{41} + 20\cdot\frac{68}{41} = \frac{75 + 1360}{41} = \frac{1435}{41} = 35$ । ଉଭୟ ସମୀକରଣ ସିଦ୍ଧ ହେଉଛି ।

ଉତ୍ତର : $x = \frac{41}{25},\ y = \frac{68}{41}$ ଅର୍ଥାତ୍ ନିର୍ଣ୍ଣେୟ ସମାଧାନ $\left(\frac{41}{25},\ \frac{68}{41}\right)$ ।

(iii) $2x - \frac{3}{y} = 9,\ 3x + \frac{7}{y} = 2$ $(y \neq 0)$

    📖 ଅନୁଚ୍ଛେଦ 1.2. (ସହ ସମୀକରଣଦ୍ୱୟର ବୀଜଗାଣିତିକ ସମାଧାନ) — (II) ଅପସାରଣ ପଦ୍ଧତି
  1. $\frac{1}{y} = v$ ନେଲେ ଦତ୍ତ ସମୀକରଣ ଦ୍ୱୟ ହେବ,
    2x - 3v = 9 \quad \ldots(1), \qquad 3x + 7v = 2 \quad \ldots(2)
  2. $x$ ର ସହଗ ସମାନ କରିବା ପାଇଁ (1) କୁ 3 ଓ (2) କୁ 2 ଦ୍ୱାରା ଗୁଣନ କଲେ,
    6x - 9v = 27 \quad \ldots(3), \qquad 6x + 14v = 4 \quad \ldots(4)
  3. (4) ରୁ (3) କୁ ବିୟୋଗ କଲେ,
    23v = -23 \Rightarrow v = -1
  4. $v = -1$ କୁ (1) ରେ ବସାଇଲେ $2x + 3 = 9 \Rightarrow x = 3$ । ପୁଣି $\frac{1}{y} = -1 \Rightarrow y = -1$ ।
  5. ଯାଞ୍ଚ : $2(3) - \frac{3}{-1} = 6 + 3 = 9$ ଏବଂ $3(3) + \frac{7}{-1} = 9 - 7 = 2$ । ଉଭୟ ସମୀକରଣ ସିଦ୍ଧ ହେଉଛି ।

ଉତ୍ତର : $x = 3,\ y = -1$ ଅର୍ଥାତ୍ ନିର୍ଣ୍ଣେୟ ସମାଧାନ $(3,\ -1)$ ।

(iv) $4x + 6y = 3xy,\ 8x + 9y = 5xy$ $(x \neq 0,\ y \neq 0)$

    \frac{4}{y} + \frac{6}{x} = 3, \qquad \frac{8}{y} + \frac{9}{x} = 5
  2. $\frac{1}{x} = u$ ଓ $\frac{1}{y} = v$ ନେଲେ,
    6u + 4v = 3 \quad \ldots(1), \qquad 9u + 8v = 5 \quad \ldots(2)
  3. (1) କୁ 2 ଦ୍ୱାରା ଗୁଣନ କରି (2) କୁ ତାହାରୁ ବିୟୋଗ କଲେ,
    (12u + 8v) - (9u + 8v) = 6 - 5 \Rightarrow 3u = 1 \Rightarrow u = \frac{1}{3}
  4. $u = \frac{1}{3}$ କୁ (1) ରେ ବସାଇଲେ $2 + 4v = 3 \Rightarrow v = \frac{1}{4}$ ।
  5. ଅତଏବ $x = \frac{1}{u} = 3$ ଓ $y = \frac{1}{v} = 4$ ।

(v) $(a-b)\,x + (a+b)\,y = a^2 - 2ab - b^2$ $(a+b)\,x + (a+b)y = a^2 + b^2$

ବ୍ୟବହୃତ ସୂତ୍ର (ପୂର୍ବପରି)
  • ଅପସାରଣ ପଦ୍ଧତି : ସହଗ ସମାନ କରି ଯୋଗ ବା ବିୟୋଗ ଦ୍ୱାରା ଗୋଟିଏ ରାଶିକୁ ଅପସାରଣ
    a_2(a_1x + b_1y + c_1) - a_1(a_2x + b_2y + c_2) = 0 \Rightarrow (a_2b_1 - a_1b_2)\,y + (a_2c_1 - a_1c_2) = 0
    📖 ଅନୁଚ୍ଛେଦ 1.2. (ସହ ସମୀକରଣଦ୍ୱୟର ବୀଜଗାଣିତିକ ସମାଧାନ) — (II) ଅପସାରଣ ପଦ୍ଧତି
  1. ଦତ୍ତ ସହସମୀକରଣ ଦ୍ୱୟ :
    (a - b)\,x + (a + b)\,y = a^2 - 2ab - b^2 \quad \ldots(1), \qquad (a + b)\,x + (a + b)\,y = a^2 + b^2 \quad \ldots(2)
  2. ଉଭୟ ସମୀକରଣରେ $y$ ର ସହଗ $(a + b)$ ସମାନ । ତେଣୁ (2) ରୁ (1) କୁ ବିୟୋଗ କଲେ $y$ ଅପସାରିତ ହୁଏ :
    \{(a + b) - (a - b)\}\,x = a^2 + b^2 - a^2 + 2ab + b^2 \Rightarrow 2b\,x = 2b^2 + 2ab
  3. $b \neq 0$ ହେଲେ ଉଭୟ ପାର୍ଶ୍ୱକୁ $2b$ ଦ୍ୱାରା ହରଣ କଲେ,
    x = b + a = a + b
  4. $x = a + b$ କୁ (2) ରେ ବସାଇଲେ ($a + b \neq 0$),
    (a + b)^2 + (a + b)\,y = a^2 + b^2 \Rightarrow (a + b)\,y = a^2 + b^2 - (a^2 + 2ab + b^2) = -2ab \Rightarrow y = \frac{-2ab}{a + b}
  5. ଯାଞ୍ଚ : (1) ରେ $(a - b)(a + b) - 2ab = a^2 - b^2 - 2ab$ ଏବଂ (2) ରେ $(a + b)^2 - 2ab = a^2 + b^2$ । ଉଭୟ ସମୀକରଣ ସିଦ୍ଧ ହେଉଛି ।

ଉତ୍ତର : $x = a + b,\ y = \frac{-2ab}{a + b}$ ଅର୍ଥାତ୍ ନିର୍ଣ୍ଣେୟ ସମାଧାନ $\left(a + b,\ \frac{-2ab}{a + b}\right)$ ।

(vi) $\frac{x}{a} + \frac{y}{b} = 2,\ ax - by = a^2 - b^2$

    a_2(a_1x + b_1y + c_1) - a_1(a_2x + b_2y + c_2) = 0 \Rightarrow (a_2b_1 - a_1b_2)\,y + (a_2c_1 - a_1c_2) = 0
    📖 ଅନୁଚ୍ଛେଦ 1.2. (ସହ ସମୀକରଣଦ୍ୱୟର ବୀଜଗାଣିତିକ ସମାଧାନ) — (II) ଅପସାରଣ ପଦ୍ଧତି

6ପ୍ରଶ୍ନ

Cramer ଙ୍କ ନିୟମ ପ୍ରୟୋଗ କରି ନିମ୍ନ ସହସମୀକରଣମାନଙ୍କର ସମାଧାନ କର :

ପଦ୍ଧତି : Cramer ଙ୍କ ନିୟମରେ ସହଗମାନଙ୍କ ଡିଟରମିନାଣ୍ଟ $\Delta$, ଏବଂ $x$ ଓ $y$ ର ସ୍ତମ୍ଭରେ ଧ୍ରୁବକ ପଦ ବସାଇ $\Delta_x$ ଓ $\Delta_y$ ନିର୍ଣ୍ଣୟ କରାଯାଏ । $\Delta \neq 0$ ହେଲେ $x = \frac{\Delta_x}{\Delta}$ ଓ $y = \frac{\Delta_y}{\Delta}$ ।

(i) $2x + 3y = 5,\ 3x + y = 4$
